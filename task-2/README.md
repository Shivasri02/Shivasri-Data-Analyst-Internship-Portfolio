# 📊 Exploratory Data Analysis (EDA) & Business Intelligence

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore dataset to uncover key business insights related to sales, profit, and customer behavior.

## 📂 Dataset
- Name: Sample Superstore Dataset  
- Rows: 9,994  
- Columns: 21  

### Key Features:
- Order Date, Ship Date  
- Sales, Profit, Quantity, Discount  
- Category, Sub-Category  
- Region, State, City  

## 🛠 Tools & Technologies
- Python (Pandas, Matplotlib, Seaborn)  
- SQL  
- Excel / PowerPoint  

## 🔍 Steps Performed

### 1. Data Understanding
- Checked dataset structure and data types  
- Verified absence of missing values  

### 2. Data Cleaning
- Removed duplicates  
- Converted date columns to datetime format  
- Created new feature: **Month**

### 3. Data Analysis
- Performed univariate and multivariate analysis  
- Generated visualizations  

### 4. Business Intelligence
- Used SQL to answer business questions  
- Identified trends and performance patterns  

## 📊 Key Insights
- Technology category has highest sales  
- West region performs best  
- Some transactions result in losses  
- High sales do not always mean high profit  
- Monthly sales show variation  

## 📈 Visualizations
- Sales by Category (Bar Chart)  
- Sales by Region (Bar Chart)  
- Sales vs Profit (Scatter Plot)  
- Monthly Sales Trend (Line Chart)  
- Profit Distribution (Histogram)  

## 💡 Business Questions Answered
- Top-performing categories  
- Highest revenue region  
- Sales vs profit relationship  
- Monthly trends  
- Loss-making transactions
